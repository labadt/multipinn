# MULTIPINN

MULTIPINN — фреймворк для Physics-Informed Neural Networks (PINNs) на Python и PyTorch.

## Основная инструкция

Каноническая инструкция по установке и первому запуску находится в файле:

- [`guide/getting_started.ipynb`](guide/getting-started.ipynb)

Все пользовательские инструкции в репозитории должны использовать единый базовый вариант:

- **Поддерживаемые версии Python:** `3.8` – `3.11`
- **Рекомендуемая версия для нового окружения:** `3.10`
- **Основная команда установки:** `pip install -e .`

## Минимальные технические требования

Требования к аппаратным ресурсам существенно зависят от класса решаемой задачи,
поэтому они приводятся отдельно для установки библиотеки, для лёгких 2D-экспериментов
и для вычислительно сложных 3D / multi-GPU экспериментов.

| Компонент | Минимум для установки и unit-тестов | Рекомендуемо для 2D экспериментов | Рекомендуемо для 3D / multi-GPU экспериментов |
|---|---|---|---|
| ОС | Linux x86_64 / Windows 10+ | Linux x86_64 | Linux x86_64 |
| CPU | 4 ядра | 8 ядер | 16+ ядер |
| RAM | 16 ГБ | 32 ГБ | 128 ГБ и более |
| Диск | 20 ГБ SSD | 100 ГБ SSD | 200+ ГБ SSD |
| GPU | Не обязателен | NVIDIA GPU с поддержкой CUDA | NVIDIA A100 или вычислительно сопоставимый ускоритель |
| VRAM | Не обязателен | от 8–12 ГБ | от 40 ГБ |
| CUDA | Не обязателен | Совместимая с PyTorch | Совместимая с PyTorch |

Наиболее тяжёлые эксперименты воспроизводились на вычислительном узле на базе процессора
AMD EPYC 7313 (16 ядер, производительность порядка 0,28 TFLOPS FP64) и ускорителей класса
NVIDIA A100 или вычислительно сопоставимых аналогов. Для части трёхмерных постановок рост
числа точек коллокации приводит к существенному росту потребления видеопамяти, что следует
учитывать при выборе вычислительной конфигурации.

Программное окружение: Python `3.8`–`3.11`, PyTorch совместимой версии, драйвер NVIDIA
и CUDA-окружение для запусков на GPU, зависимости из `requirements.txt`, а для GNN-сценариев —
пакеты семейства `torch-geometric`, подбираемые под версию CUDA и PyTorch.

Полная таблица требований также приведена в
[README.md](https://github.com/multipinn/multipinn/blob/main/README.md#minimum-hardware-requirements).

## Быстрый старт

```bash
git clone https://github.com/multipinn/multipinn.git
cd multipinn
python -m pip install --upgrade pip
pip install -e .
python -m examples.poisson_2D_1C.run_train
```
